Sometimes it is necesarry or useful to downgrade an installed package, particularly if a bug has been introduced.

## Cachy OS

Cachy ships with the useful `downgrade` tool, where all you have to do is run `downgrade <package>` and then select the version you want to downgrade to in the menu that opens up.
